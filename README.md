# Vector Click

Vector Click is a free, portable Windows mouse and keyboard automation utility for repetitive tasks, testing, accessibility-related workflows, and other permitted automation. It supports mouse and keyboard actions, fixed or randomized timing, repeat patterns, current or fixed cursor positions, selected-window targeting, safety hotkeys, live status, optional Windows scheduling controls, optional screen-capture hiding, and optional portable settings.

It aims for broad Windows compatibility, but compatibility does not mean permission. Vector Click is designed to work with as many applications as reasonably possible, not specifically to evade or defeat access controls, anti-cheat systems, security boundaries, or platform rules. A compatible application may still permit, ignore, restrict, detect, or block synthetic input. Review the applicable rules, terms of service, EULA, and automation policies before use. Do not use Vector Click in multiplayer or competitive experiences.

## Highlights

- Mouse and keyboard input with Single, Double, Triple, Burst, and Hold actions
- Fixed intervals or randomized intervals with Independent, Drifting, and Natural variation styles
- Minutes, Seconds, and Milliseconds timing fields for configurable timing values
- Current cursor position or a captured fixed screen position
- Several ways to send mouse and keyboard input, including to a selected compatible window
- Dedicated global Start / Stop and Emergency Stop hotkeys
- Optional Scheduling & Performance controls that default to Windows-managed behavior
- Built-in safeguards for clean stopping, protected keys, and input-rate limits
- Optional screen-capture hiding for Vector Click windows on supported Windows systems
- Optional portable settings stored beside the executable
- Named local profiles for saving and reusing different setups
- Native dark interface with Basic, Advanced, and About pages
- No telemetry, background updater, driver, service, or injected module

## Project Direction

Privacy-respecting, non-intrusive behavior and clear disclosure are core project principles. Current official releases do not require telemetry, advertisements, accounts, hidden network activity, injected modules, drivers, services, or forced updates.

Vector Click also aims to balance useful depth with an approachable workflow. New features should solve practical automation needs without making ordinary use depend on a general-purpose scripting or workflow-building system.

Features, platforms, packaging, support, and other project decisions may change. Material changes involving privacy, monetization, networking, installation, background behavior, or system integration should be documented. Third-party forks and redistributed builds may follow different policies.

## Availability, Contact, and Contributing

Official releases from the original maintainer are intended to remain free to use, with no required payment or forced paywall. Donations may be accepted but are optional. This does not control third-party forks, redistributed builds, or decisions made under different future ownership.

The official source is the [Vector Click GitHub repository](https://github.com/ZeroTraceAPI/Vector-Click). When sharing, forking, modifying, packaging, or redistributing Vector Click, please link back to the official repository so users can find a clean and current copy.
